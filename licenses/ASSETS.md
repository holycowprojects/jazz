# Vendored/third-party asset licensing record

Task 27f. One entry per third-party creative asset JAZZ's install pulls in
or vendors into the repo, covering everything from Task 27c (icon system)
and Task 27e (Qt/GTK compat layer) at minimum. Package dependencies with
no distinct creative-asset licensing question (fonts from Task 27a's
`typography.json`, general system packages) are tracked via `pacman`
itself, not repeated here - this file is for things JAZZ's own look
directly depends on: icon art, theme art, wallpaper art.

## Lucide (icon glyphs)

- **Source:** https://lucide.dev/ / https://github.com/lucide-icons/lucide
- **Author:** Lucide contributors (fork of Feather Icons)
- **License:** ISC
- **Files:** `design/icons/symbols/*.svg` (10 icons: ai, battery, clipboard,
  lock, notifications, now-playing, power, settings, widgets, wifi - 3 of
  these ship as `-ondark`/`-onlight` pairs, 13 files total)
- **Modifications:** normalized to a 24x24 canvas, 1.8px stroke (from
  Lucide's default 2px), round linecap/linejoin, `fill: none`; color baked
  in directly per file instead of Lucide's `stroke="currentColor"`, since
  Quickshell's software rendering backend on this hardware
  (`QT_QUICK_BACKEND=software`) can't do the shader-based recoloring
  (`ColorOverlay`/`MultiEffect`) that would let one SVG serve every theme -
  see `design/icons/symbols/SOURCE.md` for the full rationale.

## Papirus (icon theme, third-party app fallback)

- **Source:** https://github.com/PapirusDevelopmentTeam/papirus-icon-theme
- **License:** GPL-3.0
- **Installed as:** `papirus-icon-theme` (official Arch `extra` repo
  package, not vendored into the repo - pulled in by `scripts/setup-dock.sh`)
- **Modifications:** none. Used as-is for third-party apps whose own
  `.desktop` icon lookup needs a real icon theme present (JAZZ's own dock/
  launcher/Settings icons are the Lucide set above, not Papirus).

## KvArcDark (Kvantum base theme)

- **Source:** bundled with the official `kvantum` package (Arch `extra`
  repo, `1.1.8-1`), taken from `/usr/share/Kvantum/KvArcDark/` on the
  installed system
- **Author:** Tsu Jan (Kvantum's maintainer)
- **License:** GPL-3.0-or-later (confirmed via `pacman -Qi kvantum`)
- **Files:** `configs/kvantum/JazzBase.{kvconfig,svg}`
- **Modifications:** the vendored `JazzBase.{kvconfig,svg}` here are unmodified.
  `jazz-theme-set` (Task 27e/27d) generates a real per-JAZZ-theme
  `.kvconfig` **and** `.svg` at install/theme-switch time by substituting
  KvArcDark's hardcoded color values with each JAZZ theme's own tokens
  from `design/tokens/themes.json` - the SVG needs this too, since
  KvArcDark bakes its accent-blue family directly into shape fills
  (checkbox ticks, focus rings), not purely via `.kvconfig`; the vendored
  templates here are never edited in place. See `configs/kvantum/SOURCE.md`.

## adw-gtk3 (GTK3 theme)

- **Source:** https://github.com/lassekongo83/adw-gtk3
- **License:** LGPL-2.1-only (confirmed via `pacman -Qi adw-gtk-theme`)
- **Installed as:** `adw-gtk-theme` (official Arch `extra` repo package,
  not vendored into the repo - pulled in by `scripts/setup-kvantum.sh`)
- **Modifications:** none. `jazz-theme-set` selects between its bundled
  `adw-gtk3` (light) and `adw-gtk3-dark` (dark) variants per JAZZ theme
  mode via `~/.config/gtk-3.0/settings.ini` - no theme content is edited.

## Wallpaper art (Forge, Warm)

- **Source:** AI-generated via Recraft (Akash's own account/generation,
  not a third-party stock asset with separate licensing terms attached)
- **Files:** `jazz-wallpaper-forge-canyon.png`, `jazz-wallpaper-warm-canyon.png`
  (deployed to `~/.local/share/jazz/wallpapers/` on the installed guest -
  not committed as binaries into the repo itself, same as every other
  wallpaper variant; `design/tokens/themes.json` tracks filenames/status)
- **Modifications:** cropped to 1920x1080, color-graded to each theme's
  palette via `grade_wallpaper.py` (duotone luminance mapping from the
  theme's surface/accent/highlight tokens, fire glow preserved as a warm
  focal accent) - not redistributed further, generated for JAZZ's own use.
